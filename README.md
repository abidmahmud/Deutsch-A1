# Netzwerk neu A1 · Glossar Deutsch–বাংলা

Mein Wortschatz-Trainer für Netzwerk neu A1, mit Bedeutungen und Aussprache auf Bangla.
আমার Netzwerk neu A1-এর শব্দভাণ্ডার অনুশীলনের অ্যাপ — বাংলা অর্থ ও উচ্চারণসহ।

- 1,875 words in 12 chapters, with Bangla meanings and Bangla-script pronunciation
- Flashcards with spaced repetition, a quiz (meaning, pictures, der/die/das, plural, verb forms, spelling, listening)
- 49 short reading texts, grammar and pronunciation guides
- Colour, shape and pattern code for der · die · das, plus ending rules
- Stylus notes on every page, works offline once installed

Open the GitHub Pages link in Chrome and choose **Install app**. Progress is saved on the device; use *Fortschritt → Daten exportieren* to move it to another device.
